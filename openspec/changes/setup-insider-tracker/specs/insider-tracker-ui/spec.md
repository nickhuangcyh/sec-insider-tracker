## ADDED Requirements

### Requirement: 數據分片加載
前端頁面必須先讀取索引檔案，再根據需要加載特定的日期數據檔案。

#### Scenario: 初始加載最新數據
- **WHEN** 網頁加載完成
- **THEN** 前端應先獲取 `./data/index.json`，隨後根據索引中排在首位的日期獲取對應的 `YYYY-MM-DD.json` 並渲染表格

### Requirement: 交易類型視覺標示
系統必須根據交易類型（買入或賣出）提供清晰的視覺區分。

#### Scenario: 標示買入與賣出
- **WHEN** 顯示交易列表
- **THEN** 「買入 (Buy)」交易應以綠色或正向色調標示，「賣出 (Sell)」交易應以紅色或負向色調標示

### Requirement: 金額格式化
所有交易金額和價值必須以易讀的格式顯示（如包含千分位撇號）。

#### Scenario: 顯示貨幣格式
- **WHEN** 顯示交易價值
- **THEN** 數值應顯示為如 `$1,234,567.00` 的格式
